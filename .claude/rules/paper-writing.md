# Paper Writing Rules

- Use elsarticle document class conventions
- Every factual claim requires a \cite{} with a real reference key
- Never fabricate citations — use "TODO: find citation" if unsure
- Cross-references use \ref{} with descriptive labels (sec:cap-fidelity not sec:2.1)
- Tables and figures need \label{} and must be referenced in text
- Compress red-ocean content (well-surveyed topics) into tables
- Preserve blue-ocean content (novel contributions) in full prose
- No emoji in academic text
- British/American spelling must be consistent (pick one)
